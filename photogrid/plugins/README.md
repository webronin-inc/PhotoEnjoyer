# Плагины PhotoGrid

Каждый плагин — отдельный `.py`-файл в этой папке. При запуске приложение
автоматически находит все файлы (кроме `_*` и `loader.py`) и вызывает у них
функцию `register(app)`.

## Минимальный плагин

```python
def register(app):
    print("Привет из плагина!")
    app.add_menu_item("Файл", "Мой пункт", lambda: print("Клик"))
