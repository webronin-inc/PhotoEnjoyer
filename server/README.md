# Сервер PhotoEnjoyer (лицензии, аккаунты, админка, библиотека)

Чистый WSGI на стандартной библиотеке + `cryptography`, база SQLite. Подходит для
бесплатного/дешёвого тарифа PythonAnywhere: один процесс, без фоновых задач.

Что делает сервер: регистрация по ключу, вход, привязка устройств, подписанные
токены (программа проверяет их офлайн), журнал событий, админ-API, библиотека
шаблонов, новости, режим техработ и минимальная версия программы.
**Фото пользователей на сервер не попадают.**

## Развёртывание на PythonAnywhere (≈ 15 минут)

1. Зарегистрируйтесь на pythonanywhere.com. Адрес сайта будет
   `https://ВАШ_ЛОГИН.pythonanywhere.com` (HTTPS включён автоматически).
2. Вкладка **Consoles → Bash**. Склонируйте репозиторий и поставьте зависимость:
   ```bash
   git clone https://github.com/webronin-inc/PhotoEnjoyer.git
   cd PhotoEnjoyer
   pip install --user cryptography     # на PythonAnywhere обычно уже есть
   ```
   Если репозиторий приватный — используйте токен или загрузите папку `server/`
   через вкладку **Files** (нужна только она).
3. Создайте базу и **ключ подписи** (хранится только на сервере) и администратора:
   ```bash
   export PE_DATA_DIR=$HOME/photoenjoyer_data
   python -m server.manage init
   python -m server.manage create-admin admin     # спросит пароль (от 8 символов)
   python -m server.manage public-key > public.pem
   ```
   Команда `init` печатает **открытый ключ** — он нужен программе (шаг 6).
4. Вкладка **Web → Add a new web app → Manual configuration → Python 3.10+**.
   - *Source code*: `/home/ВАШ_ЛОГИН/PhotoEnjoyer`
   - *WSGI configuration file* (ссылка на странице) — замените содержимое на:
     ```python
     import os, sys
     sys.path.insert(0, "/home/ВАШ_ЛОГИН/PhotoEnjoyer")
     os.environ["PE_DATA_DIR"] = "/home/ВАШ_ЛОГИН/photoenjoyer_data"
     from server.wsgi import application
     ```
   - Нажмите **Reload**. Проверка: откройте
     `https://ВАШ_ЛОГИН.pythonanywhere.com/api/v1/status` — придёт JSON с `"ok": true`.
5. Выпустите первые ключи (в той же Bash-консоли):
   ```bash
   python -m server.manage make-keys 5 --days 30 --devices 1 --plan "Стандарт"
   ```
   Позже ключи удобнее выпускать из админки внутри программы.
6. **Подключите программу к серверу** (в репозитории программы):
   - впишите адрес в `photogrid/server_config.py`:
     `SERVER_URL = "https://ВАШ_ЛОГИН.pythonanywhere.com"`
   - сохраните открытый ключ из шага 3 как `photogrid/license_pub.pem`
   - выпустите версию — после обновления у всех появится окно входа.
   Пока оба пункта не выполнены, окно входа **не включается** (так безопасно
   выпускать сборки до развёртывания сервера).

## Эксплуатация

- **Бэкап:** копируйте папку `photoenjoyer_data` (там база и `license_private.pem`).
  Потеряете приватный ключ — все токены станут недействительными, программе
  придётся выпустить новый открытый ключ.
- **Бесплатный тариф:** один веб-процесс (запросы идут по очереди), лимит на CPU
  в сутки, нет своего домена и фоновых задач. Для десятков пользователей этого
  хватает; если вырастете — платный тариф без изменений в коде. Бесплатные
  веб-приложения нужно периодически «продлевать» кнопкой на вкладке Web —
  проверьте условия на сайте хостинга.
- **Техработы/блокировка старых версий:** админка → «Сервер» (режим техработ,
  минимальная версия, ссылка на обновление).
- **Права пользователей:** удаление аккаунта вместе с данными доступно самому
  пользователю в личном кабинете и администратору.

## Безопасность — что важно знать

- Пароли хранятся как scrypt-хеш, IP — только соль-хеш, события — из белого списка.
- Лимит попыток входа: 5 неудач на логин / 30 на IP за 15 минут → блокировка.
- Токен подписан Ed25519, живёт 7 дней (это и есть «офлайн-запас»).
- Исходный код программы открыт, а значит проверку входа в клиенте можно
  вырезать в собственной сборке. Реальная защита — это приватный репозиторий,
  раздача установщика только вошедшим и ценность, которая живёт на сервере
  (библиотека, обновления). Подробнее — в docs/SIGNING.md, раздел «Что защищает».
