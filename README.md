PhotoEnjoyer — подробный обзор режимов и возможностей

📸 О приложении
PhotoEnjoyer — это удобный инструмент для сборки четырёх фотографий в единую композицию. Программа подойдёт для создания коллажей, сравнительных таблиц, пошаговых инструкций и просто красивых раскладок из любимых снимков.

🧩 Режимы раскладки
В приложении доступно несколько вариантов компоновки фотографий — от классических до нестандартных. Каждый режим можно настроить под свои задачи.
1. Раскладка 2×2 (классическая сетка)
Две фотографии в ряд, две — в столбец. Идеально подходит для:
- сравнения «до/после»;
- коллажей из четырёх кадров;
- наглядных подборок.

2. Раскладка 4×1 (горизонтальная лента)
Четыре снимка выстраиваются в один ряд слева направо. Отличный выбор для:
- панорамных подборок;
- пошаговых инструкций;
- лент событий.

3. Раскладка 1×4 (вертикальная лента)
Четыре фотографии располагаются в один столбец сверху вниз. Удобно для:
- мобильных скриншотов;
- историй и таймлайнов;
- вертикальных сравнений.

4. Свободные рамки и отступы
Настройка внешнего вида: толщина и цвет рамок, внутренние отступы между снимками, скругления углов — всё для того, чтобы композиция выглядела аккуратно и стильно.
👀 Предпросмотр
Изменения отображаются в реальном времени: вы сразу видите, как будет выглядеть итоговая таблица, и можете оперативно подкорректировать раскладку, рамки и порядок фотографий.
🏷️ Подписи
Под каждым фото есть поле для подписи. Кнопка в шапке списка фото (или «Инструменты → Подписи…» на боковой панели) открывает окно настроек с живым образцом:
- стиль: плашка, капсула или текст с контуром; положение сверху или снизу; выравнивание;
- шрифт (Times New Roman, Arial, Segoe UI, Georgia и др.), жирный и курсив, размер, число строк (до 4);
- цвет текста, цвет и прозрачность подложки, тень;
- быстрые действия: нумерация по шаблону («Шаг {n}»), подписи из имён файлов, одна подпись для всех, очистка. Все они отменяются Ctrl+Z.
Настройки сохраняются между запусками.
⌨️ Горячие клавиши на любой раскладке
Все сочетания с Ctrl работают и на русской раскладке (Ctrl+Ы = Ctrl+S, Ctrl+С/М = копировать/вставить в полях ввода). Полный список — в «О программе → Горячие клавиши».

🧭 Боковая панель
Коллаж · Шаблоны · Пакетная обработка · Облако · Редактор фото · Инструменты (все действия плагинов: подписи, водяной знак, PDF…) · Плагины. Внизу: тема, настройки, обновление, «О программе». Иконки — собственный набор 3D-неона; анимации можно переключить на «Мягкие» или «Выкл» в настройках.

🖱️ Drag & Drop
Перетаскивайте фотографии мышью прямо в нужные ячейки — интуитивно понятное управление без лишних кликов. Можно менять снимки местами и быстро собирать нужную композицию.
🔌 Плагины
Приложение поддерживает расширения: дополнительные раскладки, эффекты и инструменты можно подключать через плагины — функциональность легко расширить под собственные задачи.

⚙️ Установка
- Запустите установщик PhotoEnjoyer-Setup-*.exe.
- Выберите папку для установки.
- Поставьте галочку «Создать ярлык на рабочем столе» — и ярлык появится на рабочем столе.
- Готово — можно запускать и пользоваться.

🔔 Обновления
Приложение автоматически проверяет наличие новых версий:
- при каждом запуске;
- каждые 6 часов в фоновом режиме.
- Если доступно обновление — в шапке приложения появится значок 🔔, по которому можно перейти к установке новой версии.
