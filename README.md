# PhotoEnjoyer

Собирает 4 фотографии в одну таблицу: раскладки 2×2, 4×1, 1×4, рамки,
предпросмотр, drag & drop, плагины.

## Установка

1. Запустите `PhotoEnjoyer-Setup-*.exe`.
2. Выберите папку установки.
3. Поставьте галочку «Создать ярлык на рабочем столе».
4. Готово.

## Обновления

Приложение автоматически проверяет обновления при запуске
и раз в 6 часов. Если доступна новая версия — в шапке появится 🔔.
